Activity 2

Git and GitHub setup

Installing Git, connecting it to GitHub, and publishing a repository for the first time.

What it covers

  • Installing and configuring Git
  • Creating a GitHub account and repository
  • Committing changes locally
  • Pushing a local repository to GitHub

What I learned

  • Version control keeps a history of every change
  • Local and remote repositories work together
  • GitHub stores code online and makes it easy to share

Core Git workflow

# one-time setup
git config --global user.name "Your Name"
git config --global user.email "you@example.com"

# create, commit, publish
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin <repository-url>
git push -u origin main

Activity 3

GitLens and Live Share

Two VS Code extensions: one for understanding code history, one for coding together in real time.

What it covers

  • Installing GitLens and viewing who changed each line and when
  • Browsing commit history from inside the editor
  • Installing Live Share and starting a shared session
  • Editing the same project with another person at the same time

What I learned

  • Commit history explains why code looks the way it does
  • GitLens makes Git information visible while I work
  • Live Share supports pair programming and team collaboration

LeetCode practice repository

A GitHub repository that stores my LeetCode solutions, so my practice is organised and visible.

What it covers

  • Small, frequent commits create a clear record of progress
  • Clear structure and notes make old solutions easy to revisit

Learning journey

How the four activities connect, in the order I completed them.

  1. Set up the editor

    VS Code became my workspace for writing and running code.

  2. Track the work

    Git and GitHub gave my code a history and a home online.

  3. Understand and share

    GitLens and Live Share helped me read history and code with others.

  4. Practise and publish

    The LeetCode repository put every earlier skill to use.

Together, these activities form one workflow: write code in an editor, track it with Git, understand and share it with GitLens and Live Share, and publish practice work on GitHub.
