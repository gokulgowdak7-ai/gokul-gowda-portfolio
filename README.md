# Gokul Gowda – Portfolio

Personal portfolio for the AI-Assisted Portfolio Blog activity. One file, no build step.

## Edit your links

Open `index.html`, find the `LINKS` object near the bottom, and replace each `YOUR-...` placeholder. All links and contact entries update from there.

## Add screenshots

1. Create an `images` folder next to `index.html` and add your screenshots.
2. In each "Proof of work" box, replace the dashed box content with:
   `<img src="images/your-file.png" alt="Describe the screenshot">`

## Publish on GitHub Pages

1. Create a repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html` (and the `images` folder).
3. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your site goes live at `https://YOUR-USERNAME.github.io` in a minute or two.
